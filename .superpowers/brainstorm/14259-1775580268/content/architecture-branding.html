Key Architecture Decisions

  • TVProtocol — defines: connect(), disconnect(), sendCommand(), getState(), launchApp(), sendText()
  • TVDevice — model: name, IP, platform, MAC address, capabilities, pairing status
  • TVState — observable: current app, playback status, volume, power, input field focused
  • DiscoveryService — scans via mDNS (Android TV, LG) + SSDP (Samsung, Roku) simultaneously
  • ConnectionManager — handles pairing, reconnection, and auth persistence per device
