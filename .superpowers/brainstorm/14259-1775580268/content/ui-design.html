Context Switching Logic

How the UI auto-adapts:
• Navigation mode — default when TV is on home screen or browsing menus
• Media mode — triggers when TVState.playbackStatus != .idle (video/music detected)
• Keyboard mode — triggers when TVState.inputFieldFocused == true
• App launcher — manual (swipe up gesture or button tap)
• User can always override by swiping left/right to switch modes manually
• Small mode indicator dots at bottom show which mode is active
