Discovery Technical Details

DISCOVERY PROTOCOLS
• mDNS — Android TV (_androidtvremote2._tcp)
• SSDP — Roku (roku:ecp), Samsung
• mDNS — LG webOS (_lge-disc._tcp)
• mDNS — Fire TV (shares Android TV service)
• Scans run simultaneously on app launch
CONNECTION LIFECYCLE
• First time — discover → select → pair (PIN) → save
• Returning — auto-connect to last device on launch
• Reconnect — automatic retry with exponential backoff
• Multi-device — save multiple TVs, switch via device picker
• Auth tokens stored in Keychain

User Flow Summary

First launch: App opens → auto-scan → show device list → user taps TV → pairing PIN → connected → remote UI
Subsequent: App opens → auto-connect to last TV → remote UI (< 2 seconds)
Switch TV: Tap device name in status bar → device picker → select → connect
TV not found: Show "Add manually" option → enter IP → connect
